# Clear Skies

Clear Skies is an interactive air-quality dashboard developed as a team project for the NASA Space Apps Challenge. It presents real-time air-quality information through a responsive interface and interactive data visualizations.

## Features

- Search and view air-quality information for cities worldwide
- Display current Air Quality Index values and health categories
- Show measurements for pollutants such as PM2.5, PM10, NO2, O3, SO2, and CO
- Present environmental information through responsive visualizations
- Retrieve live air-quality information through API calls

## Technologies

- React
- JavaScript
- Vite
- HTML and CSS
- Tailwind CSS
- Axios
- Recharts
- Three.js
- Air-quality APIs
